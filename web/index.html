This is a static, same-origin browser fixture. It opens real pages and loads real modules; the deployment switch is simulated. It does not test your production site.

The published demo deliberately requests an unavailable fixture module to model retirement. Warm module-registry behavior is demonstrated with an already loaded module. The included Rust localhost controller can genuinely retire the same URL between releases. No request interception, cache disabling, service-worker manipulation, or external proxying is used.

Trace replay plays back recorded events; it is not deterministic browser replay. Automated browser verification is pending. Safari and real phones also require their own validation.
